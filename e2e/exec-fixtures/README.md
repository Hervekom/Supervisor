Synthetic data and outputs for the P9 execution tasks.

`solar.csv` and `wages.csv` are random synthetic data. Every `.txt` file is the real output of the scripts
that Supervisor gives students (pandas 3.1, statsmodels 0.15, R 4.3.3 on Linux), run on these files.
Folder paths were replaced with `/home/student/proj`. `train.txt` and the `sim*.txt` files come from small
synthetic scripts that end with the reporting lines Supervisor asks students to add. No real research data.
